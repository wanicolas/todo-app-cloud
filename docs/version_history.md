# Historique des Versions

Le suivi du cycle de vie du projet s'appuie sur une gestion sémantique des versions (Git Tagging). Le tableau ci-dessous retrace l'historique des versions majeures et mineures, montrant l'évolution continue du logiciel depuis un prototype simple local jusqu'à une architecture Cloud durcie et sécurisée.

| Version    | Date       | Type de modification         | Description des évolutions majeures                                                                                                                                                                                                                                                                                                             |
| :--------- | :--------- | :--------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **v1.0.0** | 12/04/2026 | Logiciel (Prototype initial) | - Création du prototype initial (React SPA & Express Backend).<br>- Stockage des données local (SQLite en fichier).<br>- Pas d'authentification (toutes les tâches sont publiques).                                                                                                                                                             |
| **v1.1.0** | 04/05/2026 | Qualité & Structure          | - Migration de l'ensemble du projet vers **TypeScript** (typage strict).<br>- Refonte du backend selon le modèle en **3 couches** avec injection de dépendances.<br>- Développement du premier **harnais de test unitaire Jest** (couverture initiale).                                                                                         |
| **v1.2.0** | 28/05/2026 | Logiciel & RGPD              | - Découpage en **microservices** (Client / Backend / Auth).<br>- Création d'une base MySQL dédiée pour chaque service de données.<br>- Implémentation du hachage de mots de passe (bcrypt) et de sessions JWT (HttpOnly).<br>- Ajout des fonctions RGPD : export JSON (portabilité) et suppression (droit à l'oubli).                           |
| **v2.0.0** | 22/06/2026 | CI & Packaging Helm          | - Création des Dockerfiles multi-stage (dev, test, prod).<br>- Création du **workflow d'intégration continue (CI)** automatisé sur GitHub Actions.<br>- Packaging Kubernetes à l'aide de **Charts Helm** unifiés.                                                                                                                               |
| **v2.1.0** | 20/07/2026 | Infrastructure & DevSecOps   | - **Version actuelle validée et fonctionnelle**.<br>- Provisionnement de l'infrastructure managée sur Azure (AKS, MySQL, Key Vault) via **Terraform**.<br>- Durcissement **Zero Trust** (VNet MySQL privé, NetworkPolicies Kubernetes, Key Vault CSI Secrets Provider, conteneurs Non-Root).<br>- Déploiement continu (CD) automatisé via OIDC. |
